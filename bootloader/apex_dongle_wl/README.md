# Provisional dongle port — do not flash

These board files predate the reviewed bootloader installed on the development
receiver. They include unverified hardware assumptions and are not used by
the receiver application build or the keyboard release build.

The corrected dongle bootloader and stock USB installer have not yet been
packaged in this repository. See [Receiver firmware](../../dongle/README.md)
for application updates on a receiver that already has the custom bootloader.
